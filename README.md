## 1. О проекте

Сетевые инженеры СПД ежедневно тратят часы на рутину: пинговать сотни IP вручную,
искать MAC-адрес по десяткам коммутаторов, собирать конфиги и рисовать схемы в Visio.
**NetUtils RU** автоматизирует эти задачи одной командой и работает с реальным парком
оборудования российских и азиатских вендоров.

### Ключевые возможности

| Модуль | Что делает |
|---|---|
| **Live Dashboard** | Таблица IP/hostname, автоматический пинг, цветовая индикация доступности |
| **Контекстное меню** | ПКМ по IP → выполнить команду на устройстве (show vlan, show mac, etc.) |
| **Терминал** | Встроенный вывод результата команд с подсветкой |
| **Схемы по запросу** | Построение графа связей до верхнего агрегата на основе LLDP/CDP |
| **Поиск MAC** | Поиск MAC-адреса по всей сети с визуализацией пути |
| **Экспорт** | Выгрузка инвентаризации и результатов в Excel |

### Поддерживаемое оборудование

| Вендор | Серии | Тип CLI | Статус |
|---|---|---|---|
| Qtech | QSW-3300/3400 | Huawei-like | ✅ |
| Eltex / MES | MES-14xx/24xx/34xx | Cisco-like | ✅ |
| Elektra | коммутаторы Elektra | Cisco-like | ✅ |
| Huawei | S5700, S1700 | VRP | ✅ |
| PESSO SI3000 | SI-3000-24P | Специфический | ✅ |
| ZTE | ZXR10 5928 | ZTE CLI | ✅ |

## 2. Пользовательский интерфейс и сценарии работы

Проект реализован в виде **Web-приложения** (браузер). Это позволяет инженеру не устанавливать дополнительное ПО на рабочий компьютер и работать с любого устройства в сети (включая планшеты и телефоны).

### 2.1. Главный экран (Дашборд)

Открывая браузер, инженер видит таблицу со списком всего оборудования СПД (данные берутся из `inventory.json`):
*   **Колонки:** IP-адрес, Hostname, VLAN, Вендор, Статус.
*   **Цветовая индикация:** 
    *   ⚪ Серый — устройство не опрошено или выключено.
    *   🔵 **Голубой** — устройство активно (пинг прошел успешно).
    *   🔴 Красный — устройство активно, но SSH-доступ запрещен (ошибка авторизации).
*   **Живой опрос:** При загрузке страницы запускается асинхронный пинг всех адресов (asyncio). Таблица обновляется в реальном времени без перезагрузки страницы (через HTMX).

### 2.2. Контекстное меню (ПКМ по IP)

При клике правой кнопкой мыши на активный IP-адрес открывается меню действий:
1.  **Выполнить команду:** Выбор из списка (VLAN, MAC-таблица, LLDP).
2.  **Открыть терминал:** Модальное окно с выводом консоли устройства.
3.  **Построить схему:** Генерация графа соединений до головного агрегата.
4.  **Пинг (доп):** Принудительный повторный пинг.

### 2.3. Визуализация схем (По запросу)

При выборе «Построить схему» открывается новая вкладка с интерактивным графом (Pyvis):
*   Система автоматически строит цепочку от выбранного коммутатора вверх по LLDP до маршрутизатора/агрегата.
*   Узлы раскрашены в цвета вендоров.
*   При наведении на линию показываются порты соединения (например, `GE0/0/1 ↔ GE0/0/5`).

## 3. Дополнительные инструменты (Roadmap)

В будущих версиях планируется добавить следующие утилиты для сетевого инженера:
*   **Subnet Calculator:** Встроенный калькулятор подсетей (IPv4/IPv6) с визуализацией CIDR.
*   **Config Backup:** Автоматическое сохранение конфигураций (`show running-config`) в локальный Git-репозиторий при каждом подключении.
*   **Port Map:** Карта загрузки портов (трафик и ошибки) на основе `show interface`.
*   **MAC Tracker:** Глобальный поиск MAC-адреса по всей сети с отображением полного пути (от порта до порта).

## 7. Быстрый старт
Чтобы запустить проект локально, выполните следующие шаги:

### 7.1. Установка зависимостей
Убедитесь, что у вас установлены Python 3.13 и Poetry. Затем выполните в терминале:

poetry install
poetry shell

### 7.2. Настройка переменных окружения
Создайте файл .env в корне проекта (рядом с pyproject.toml). Это необходимо для безопасного хранения паролей и настроек подключения:

SECRET_KEY=change-me
DATABASE_URL=sqlite:///./netutils.db

SSH_DEFAULT_USERNAME=getjmanov
SSH_DEFAULT_PASSWORD=
SSH_DEFAULT_PORT=22
SSH_TIMEOUT=10

TAKAKS_USERNAME=main
TAKAKS_PASSWORD=main

VLAN5_GATEWAY=10.152.114.10
VLAN5_SUBNET=10.152.114.0/24

### 7.3. Запуск веб-сервера
Запустите сервер разработки Uvicorn:

poetry run uvicorn netutils.main:app --reload --host 0.0.0.0 --port 8000
